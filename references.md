# References

Status: stable · Spec: 1.0.2-draft

## Normative — vd3 MUST conform

- **W3C ARIA Authoring Practices Guide (APG)** — component behavior: keyboard
  patterns, focus, ARIA. https://www.w3.org/WAI/ARIA/apg/
- **W3C Design Tokens (DTCG)** — token file format. https://tr.designtokens.org/

## Consulted literature — cite, don't conform

- **IBM Carbon Design System** (Apache-2.0 / open guidelines). The only external
  system worth consulting: actively maintained by IBM, most complete open
  spec set (foundations, per-component guidance, a11y reasoning). Citation
  format: "Adopt X per Carbon ⟨section⟩; deviate on Y because ⟨golden-ratio
  reason⟩."

## Excluded

- **Material 3** — deliberately not a reference. Google deprioritized Material
  on the web (Material Web Components in maintenance mode; M3 Expressive not
  implemented for web). Do not consult M3 for decisions.
